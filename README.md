# Zomato Restaurant Analytics

This project presents an end-to-end **Exploratory Data Analysis (EDA) of Bangalore's restaurant industry** using the Zomato restaurant dataset. The dataset initially contains **51,717 restaurant records and 17 features**, covering restaurant types, cuisines, locations, ratings, votes, approximate cost for two people, online ordering, table booking, and other restaurant attributes. The project begins with data cleaning and preprocessing, including handling missing values, standardising rating values, and converting pricing information into numerical format. Using **Python, Pandas, NumPy, Matplotlib, Seaborn, Plotly, and SciPy**, the analysis explores restaurant distribution, restaurant types, cuisines, locations, ratings, customer votes, pricing, online ordering, table booking, and geographical patterns across Bangalore. The analysis identifies **Quick Bites and Casual Dining** as the most common restaurant types, with **14,741 and 9,840 restaurants respectively**, while the dataset contains **2,479 cuisine combinations across 92 locations**. The average restaurant rating is approximately **3.5/5**, and the average approximate cost for two people is around **₹596.75**, with prices ranging from ₹40 to ₹6,000. Online ordering is also examined, with **27,985 restaurants accepting online orders compared with 14,959 that do not**. The project further investigates relationships between ratings, votes, pricing, online ordering, table booking, restaurant locations, and customer preferences, along with a geographical visualization of restaurant locations across Bangalore. Overall, this project demonstrates how exploratory data analysis and data visualisation can transform raw restaurant data into meaningful insights that can support decisions related to **customer preferences, pricing, restaurant services, location strategy, and business performance** in the food and hospitality industry.
